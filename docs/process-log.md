# Журнал работы с ИИ

Для раздела «Описание процесса» в конкурсной заявке. Формат записи: дата · этап · инструмент/модель · задача и ключевой промпт · результат · ошибки ИИ и исправления · скриншоты.

## 15.11.2026 · Анализ ТЗ и план
- **Инструмент:** Claude Code (desktop), модель Claude Opus 5.5.
- **Задача:** разобрать ТЗ конкурса, предложить стек, этапы и распределение ролей между моделями (Fable — архитектура и аудит, Opus — сборка, Sonnet/Haiku — рутина).
- **Результат:** план из этапов 0–6, решение хостить на своём VPS (не Vercel — нестабилен из России).

## 15.11.2026 · Исследование потребностей студентов
- **Инструмент:** Claude Code, два параллельных субагента с веб-поиском.
- **Задачи:** (1) отзывы российских студентов на ЛК и приложения вузов; (2) мировой опыт студенческих порталов и отчёты 2024–2026.
- **Результат:** `docs/01-research.md` — боли, запросы, практики, утверждённый состав разделов.
- **Ограничения ИИ:** Reddit, App Store и Google Play агентам были недоступны; цифры вендоров помечены как таковые.

## 15.11.2026 · Роли и репозиторий
- Решение: роли «студент» и «сотрудник деканата», без отдельной админки и кабинета преподавателя (ТЗ требует только кабинет студента; кабинет сотрудника — опционально).
- Репозиторий создан локально агентом, опубликован вручную через GitHub Desktop (этап вручную).
- Подготовлены документы для агентов: `CLAUDE.md`, `docs/00-tz.md`, `docs/02-architecture-brief.md`.
- Вводные команды: делаем максимально быстро, без календарного графика; VPS на Jino (2 vCPU, 8 ГБ RAM), на нём уже есть сервисы; без своего домена — технический поддомен Jino.

## 15.11.2026 · Архитектура
- **Инструмент:** Claude Code, модель переключена на **Claude Fable 5.1** в том же чате (общий контекст с Opus).
- **Промпт:** «Приступай к задаче для модели Fable с проработкой архитектуры и прочих системных элементов» + задание `docs/02-architecture-brief.md`.
- **Результат:** `docs/ARCHITECTURE.md` — стек (Next.js 15 + Prisma/PostgreSQL + Docker Compose + Caddy), модель данных, схема авторизации с правилами против IDOR, карта экранов студента и сотрудника, ИИ-помощник с GigaChat и rules-fallback (OpenAI/Anthropic недоступны с IP РФ), справки с QR, уведомления через опрос, деплой на технический поддомен Jino с HTTPS, план из 19 задач с распределением Opus/Sonnet/Haiku.
- **Допущения, принятые без уточнений:** порты 80/443 на VPS свободны (проверяется первым делом при деплое). Вуз сначала был предложен как «Ладога», команда заменила на **«Универ»**. Архитектор предложил GigaChat (ошибочное допущение: не знал о ключе команды) — заменено на шлюз-агрегатор моделей команды (работает из любой страны), ключ только в `.env` на сервере.
