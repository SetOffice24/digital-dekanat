## 15.11.2026 · Сборка прототипа
- **Инструменты:** Claude Code, модель переключена обратно на **Claude Opus 5.5** (оркестратор и основной разработчик) + субагент **Claude Sonnet 5.5** (параллельно).
- **Распределение:**
  - Opus: скелет Next.js 16, схема Prisma и сид вымышленных данных, вход и сессии, дизайн-система, все экраны студента, ИИ-помощник, деплой-файлы, тесты.
  - Sonnet (субагент, фоном): кабинет сотрудника (`/staff/*`), генерация PDF-справок с QR, страница проверки `/verify`. Получил задание с чёткими границами («не трогай файлы студента»), вернул отчёт с решениями и сомнениями.
- **Ключевой промпт субагенту (сокращённо):** «Ты — разработчик в команде… Твоя зона: repos/staff.ts, /staff/*, certificates.ts, /verify… НЕ трогай src/app/(student)/**… Проверка обязательна: tsc без ошибок, сгенерируй PDF и убедись, что кириллица встроена… В конце — отчёт: файлы, что проверено, что не получилось, решения, сомнения».
- **Ошибки ИИ и окружения, которые исправили:**
  1. Docker Desktop завис на запуске → для локальной разработки подключили встроенный PostgreSQL (`embedded-postgres`), на сервере остаётся Docker.
  2. Встроенный PostgreSQL создал базу в кодировке WIN1251 → сид упал на символе «→»; пересоздали кластер с `--encoding=UTF8`.
  3. PowerShell записал `package.json` с BOM → pnpm не читал файл; убрали BOM.
  4. Next.js 16 по умолчанию включил `cacheComponents` → страницы с сессией падали с ошибкой prerender; отключили (кабинет полностью персональный).
  5. Чужая заявка показывала «не найдено», но со статусом 200 (потоковая загрузка через `loading.tsx`) → перенесли скелетоны в отдельные разделы, теперь честный 404.
  6. React 19 сбрасывал поля формы заявки после ошибки валидации → значения возвращаются из server action.
  7. На 375 px карточки «Требует внимания» вылезали за экран (grid без `minmax(0,1fr)`) → `grid-cols-1`; проверили все экраны на 360 px.
  8. Дублировались напоминания о дедлайне (сид + автоматические) → убрали из сида, поправили расчёт дней.
  9. Субагент сгенерировал PDF вслепую — проверили визуально: исправили «г. г.», «он(а)», неверный падеж и слово «официальный» в шапке.
- **Проверено вручную в браузере (в т.ч. 360/375 px):** вход, «Сегодня», расписание, учёба, создание заявки и валидация, сотрудник переводит заявку в «Готова» → студент получает уведомление → PDF с QR → страница проверки; студент по ссылке на чужую заявку/справку получает 404, сотрудник не видит экраны студента, ИИ-помощник отвечает и готовит черновики.
- **Автотесты (этап сборки):** `tests/authz.test.ts` — 8 тестов (разделение данных во всех репозиториях, контекст ИИ без чужих данных, пароли только argon2id). Продакшен-сборка `next build` проходит.


## 15.11.2026 · Обратная связь команды: помощник и дизайн
- **Что сказала команда:** раздел ИИ-помощника не открывается; нужен дизайн в стиле образца (скриншоты экрана входа ITMO ID: пастельный фон, белая карточка, серые поля, тёмная кнопка), свой логотип «по мотивам» надписи ИТМО.
- **Ошибка ИИ №10:** страница помощника падала (destroy is not a function). Причина — эффект в стиле `useEffect(() => ref.current?.scrollIntoView())`: в новых Chrome scrollIntoView возвращает Promise, и React принял его за функцию очистки. Исправлено фигурными скобками. Ни линтер, ни сборка такую ошибку не ловят — нашли только ручной проверкой в браузере.
- **Дизайн (Opus по скриншотам-образцам):** широкий геометрический шрифт Unbounded (OFL) для заголовков, пастельная палитра «небо → сиреневый → персик», карточки со скруглением 22–32 px без рамок, поля на светло-сером фоне, тёмные кнопки, плавающая нижняя навигация, «следующая пара» на градиенте неба.
- **Логотип:** слово УНИВЕР, где «Е» собрана из трёх плашек (стопка документов / строки расписания), средняя — персиковая. Перекликается с надписью ИТМО (широкий шрифт, одна «игровая» буква), но не копирует её.
- **Фон входа:** пейзаж нарисован как SVG вручную (небо, солнце, горы, дюны) — без сторонних картинок и лицензий.

## 15.11.2026 · Адаптивность под любые экраны
- **Что сказала команда:** на широких мониторах (скриншот 1883 px) кабинет зажат в узкую колонку по центру, половина экрана пустая; на других форматах тоже.
- **Причина (ошибка проектирования ИИ №11):** каркас был ограничен max-w-6xl (≈1150 px) вместе с сайдбаром, а страницы — max-w-3xl (768 px). Проверяли только телефон и одну ширину ноутбука.
- **Что сделали (Opus):**
  - Каркас: сайдбар прижат к левому краю, контент тянется на всю ширину (до 100rem), отступы растут с шириной экрана (16 → 56 px).
  - «Сегодня»: на телефоне одна колонка в порядке важности (пара → помощник → дела → пары дня → объявления); от 1280 px — две колонки (слева пара и день, справа дела, объявления, самочувствие). Порядок на телефоне задан через order-* и display: contents, без дублирования разметки.
  - Расписание: неделя в 2 колонки от 1024 px и в 3 от 1536 px; день — пары в 2 колонки.
  - Учёба: карточки дисциплин в сетке 1/2/3 колонки; семестры и сессия — двухколоночные списки.
  - Заявки: списки в 2 колонки, карточка заявки — основное слева, история справа (липкая).
  - Кабинет сотрудника: шапка и контент на всю ширину, вкладки в шапке на десктопе.
  - Большие мониторы: базовый размер шрифта плавно растёт с 16 до 19 px (clamp), интерфейс не мельчит на 2K/4K.
- **Проверено:** 360, 768, 1024, 1883, 1920, 2560 px — горизонтальной прокрутки нет ни на одном экране; скриншоты на 1024/1883/2560 px.

## 15.11.2026 · Новый ИИ-помощник «Уни» (по образцу my.itmo)
- **Что сказала команда:** раздел помощника выглядит нестильно; приложили скриншоты ассистента my.itmo как ориентир.
- **Что взяли из образца:** помощник открывается выездной панелью поверх любой страницы (затемнённый фон), слева история чатов с «Новый чат» и группировкой по месяцам, в центре маскот + приветствие по имени + подсказки-«чипсы», ответ помощника без «пузыря» рядом с аватаром, статус «Анализирую запрос…», широкое поле ввода с круглой тёмной кнопкой и дисклеймер.
- **Что сделали своё:** маскот «Уни» (тёмный кубик с антенной и персиковой «улыбкой-плашкой» из логотипа, моргает), карточка «Черновик заявки готов» → форма заявки заполняется автоматически, плавающая кнопка «Спросить Уни» на десктопе, на телефоне — на весь экран.
- **Бэкенд:** новая сущность AiChat (миграция i_chats), API /api/assistant/chats (список, открыть, удалить), сообщения привязаны к чату; все запросы фильтруются по студенту из сессии. Добавлен тест «чужой чат не открыть, не удалить, черновик не прочитать» — всего 9 тестов.
- **Ошибки и исправления:** (12) глобальное правило :focus-visible вне слоя перебивало утилиты Tailwind 4 → синяя рамка внутри поля ввода; перенесли правило в @layer base. (13) Подпись месяца «Ноябрь 2026 г.» — убрали «г.». (14) Клиент Prisma не перегенерировался, пока работал dev-сервер (Windows блокирует DLL) — перезапуск сервера.

## 15.11.2026 · Тестирование «глазами пользователя» в Chrome и исправления
- **Что сказала команда:** у студента расписание перегружено; у «учителя» мешанина — непонятно, куда поставить оценку и где заявки. Попросили открыть сервис в Google Chrome (Claude in Chrome), пройти как пользователь и исправить.
- **Найдено в Chrome:** (а) роли преподавателя нет вообще — оценку поставить некуда; (б) у деканата сетка одинаковых карточек, «Просрочена» на 10 из 14 заявок (в сиде даты делали всё просроченным, «ждём студента» тоже считалось просрочкой), смена статуса — через абстрактный выпадающий список; (в) расписание деканата открывалось на пустом воскресенье; (г) у студента расписание с двумя переключателями, баннером и 5–6 деталями на каждой паре.
- **Сделано:**
  - **Новая роль «Преподаватель»** (миграция 	eacher_role, аккаунт 	eacher): «Мои группы» → журнал → «+ Оценка» (баллы + вид работы) → студент получает уведомление «Новая оценка». Кабинет собрал субагент Sonnet по брифу (параллельно с основной работой), тесты: чужую группу открыть и оценить нельзя (13 тестов всего).
  - **Деканат — «входящие»:** вкладки по шагам работы (Новые · В работе · Ждут студента · Готовы к выдаче · Архив) с количеством, одна кнопка действия в строке (Взять в работу / Справка готова / Отметить выданной). В карточке заявки — кнопки решений вместо списка статусов (Одобрить / Справка готова / Запросить уточнение / Отклонить). «Сводка» убрана как лишний экран.
  - **Расписание студента:** один выбор дня с числом пар под датой, по умолчанию ближайший учебный день; карточка пары: время → предмет → аудитория, мелко — вид и преподаватель; изменение одной пометкой.

## 16.11.2026 · Средний блок UX: путь пользователя для деканата и студента
- **Задача команды:** панель действий и карточка заявки, поиск у деканата, сделать путь пользователя короче и дизайн — клиентоориентированнее; проверить в Chrome.
- **Как думали о пути (Opus):** для каждой роли выписали главный сценарий и посчитали лишние шаги.   - поиск во «входящих» на лету (фамилия, имя, группа, № заявки, можно «№ 75»; строчные и «е» вместо «ё» тоже находят) + фильтр по типу; счётчики вкладок показывают найденное; «Сбросить»;

## 16.11.2026 · «Учёба»: убрали визуальный перегруз (по скриншоту команды)
- **Что сказала команда (скриншот):** списки прошлого семестра и сессии — «перегруз и не очень удобно для восприятия».
- **Разбор (Opus):** (1) две колонки с сеткой-разделителями читаются «змейкой» слева направо, а не сверху вниз; (2) у каждой строки цветная плашка — когда цветное всё, не выделяется ничего, даже долг; (3) у сессии справа две строки (плашка + дата), а дата — главное — мелким шрифтом; (4) в карточках текущего семестра — россыпь плашек со всеми оценками.
- **Сделано:**
  - прошлый семестр — список в одну колонку; оценка просто крупной цифрой с подписью «хорошо/отлично», цвет только у долга (строка подсвечена, «Долг — нужна пересдача», долги сверху); над списком — «Средний балл 4,33 · 1 долг»;
  - сессия — как календарь: крупное число и месяц слева, предмет, ниже «Экзамен · пн, 09:00 · ауд. 401»; над списком — «Первое испытание через 40 дней · всего 5»; ширина ограничена, чтобы строки не растягивались на весь экран;
  - карточки текущего семестра: вместо плашек — «Последняя: Контрольная точка, 07.11 — 8/20» и раскрывающееся «Все (4)»;
  - короче красная кнопка («Ответить деканату по пересдаче»), подпись «средний за учёбу» — чтобы не путать со средним за семестр.
- **Проверка:** Chrome (компьютер) и встроенный браузер 360 px — без горизонтальной прокрутки; типы, линтер, 18 тестов.
