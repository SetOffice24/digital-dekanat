## 4. Что готово (актуальное состояние)
**Стек:** Next.js 16.4 (App Router, cacheComponents выключен, `src/proxy.ts` вместо middleware) · React 19 · Tailwind 4 · Prisma 6 + PostgreSQL · argon2id · pdf-lib + qrcode · Docker Compose + Caddy (файлы в `deploy/`, ещё не развёрнуто).

**Роли и разделы:**
- **Студент** (`src/app/(student)`): навигация из 4 разделов — Главная · Расписание · Учёба · Заявки; справа в шапке — «Помощник», уведомления (колокольчик), профиль (аватар; «Ещё» объединено с профилем, `/more` → редирект).
  - Главная (разгружена): приветствие + одна фраза о дне, тёмная карточка ближайшей пары, «Требует внимания» (3 дела + «Показать ещё»), 3 плитки. Самочувствие — в профиле, объявления — в «Уведомления → Объявления».
  - Расписание: один выбор дня (число пар под датой), по умолчанию ближайший учебный день; карточка пары: время → предмет → аудитория, мелко вид/преподаватель.
  - Учёба: сводка «как у меня дела», семестры, сессия, пересдачи.
  - Заявки: 7 типов, трекер статусов, PDF-справка с QR + публичная `/verify/[code]`, «нужна бумага с печатью».
  - Помощник: выездная панель (по мотивам my.itmo), история чатов (`AiChat`), черновик заявки → заполненная форма. Иконка — сгенерирована OpenAI (`public/ai/assistant.webp`, исходник `docs/assistant-icon-source.png`). Имя «Уни» отменено — просто «Помощник».
- **Деканат** (`src/app/staff`): «Заявки студентов» = входящие с вкладками Новые / В работе / Ждут студента / Готовы к выдаче / Архив + кнопка действия в строке; карточка заявки — кнопки решений (Одобрить / Справка готова / Запросить уточнение / Отклонить); Объявления; Расписание (перенос/отмена пары → уведомления группе).
- **Преподаватель** (`src/app/teacher`): «Мои группы» → журнал → «+ Оценка» (баллы 0–20 + вид работы) → студенту уведомление «Новая оценка».

**Дизайн-система v3** (`src/app/globals.css`, `src/components/ui.tsx`): по мотивам rondesignlab.com — фон #FAFAFA, шрифт **Onest** (Urbanist без кириллицы), крупные заголовки, навигация-капсулы (активная чёрная), чёрные кнопки-пилюли, карточки 24–32 px, пастели со смыслом: мятный — справки, голубой — расписание, сиреневый — учёба, жёлтый — помощник/важное. Логотип — «УНИВЕР» шрифтом Unbounded, где «Е» из трёх плашек (`src/components/logo.tsx`). Вход — в стиле образца ITMO ID: фон сгенерирован OpenAI (`public/bg/login.webp`) + SVG-подложка. Адаптивность 360 px … 4K проверена.

**Вход для жюри:** на странице входа блок «Демо-доступ» — 4 кнопки входа в тестовые аккаунты без пароля (список логинов зашит на сервере, `DEMO_LOGIN=0` выключает).

**Безопасность:** данные только через репозитории (`src/server/repos/*`) с фильтром по пользователю из сессии; чужое → 404; пароли argon2id, лимит попыток; секреты только в `.env`; ИИ только через `/api/assistant`.

## 7. Подводные камни окружения
- **Docker Desktop локально не стартует** → для разработки встроенный PostgreSQL (`scripts/dev-db.mjs`, UTF-8 обязательно). Если фоновый процесс БД умер — запустить `corepack pnpm db:local` снова.
- **`prisma migrate dev` интерактивна** в этой среде → новые миграции: `prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script > prisma/migrations/<ts>_<name>/migration.sql`, затем `prisma migrate deploy`.
- **`prisma generate` падает, пока работает dev-сервер** (Windows блокирует DLL) → остановить превью, сгенерировать, запустить снова.
- **PowerShell 5 пишет UTF-8 с BOM** (`Set-Content -Encoding utf8`) → ломает package.json; писать через `[IO.File]::WriteAllText(path, text, New-Object System.Text.UTF8Encoding($false))` или инструментом Write.
- **`db:seed` сбрасывает сессии** → после сида все выходят из аккаунтов.
- **Chrome подставляет сохранённый логин** при входе → поле дописывается («dekanatteacher»); при тестах задавать значения через form_input. Скриншоты в Chrome не снимаются, если окно в фоне — визуал проверять во встроенном браузере.
- В новых Chrome `scrollIntoView` возвращает Promise → в `useEffect` всегда фигурные скобки.
- Глобальные CSS-правила — только в `@layer base`, иначе перебивают утилиты Tailwind 4.
