## 1. Что это и зачем
Прототип личного кабинета студента для конкурса «Цифровой деканат будущего» (хакатон). Вымышленный вуз **«Универ»**. Итоги конкурса — 28.11; внутренний срок команды — **19.11**, но режим работы «максимально быстро, по команде, без графика по дням».
Критерии жюри (по 10 баллов): проработанность идеи · масштаб использования ИИ (процесс, промпты, субагенты, работа с ошибками ИИ, ИИ для дизайна — **описывается в `docs/process-log.md`**) · имплементация (работает, безопасность, телефон) · качество дизайна.
ТЗ — `docs/00-tz.md`, исследование — `docs/01-research.md`, архитектура — `docs/ARCHITECTURE.md` (частично устарела, см. §4).

## 4. Что готово (актуальное состояние)
**Стек:** Next.js 16.4 (App Router, cacheComponents выключен, `src/proxy.ts` вместо middleware) · React 19 · Tailwind 4 · Prisma 6 + PostgreSQL · argon2id · pdf-lib + qrcode · Docker Compose + Caddy (файлы в `deploy/`, ещё не развёрнуто).

**Роли и разделы:**
- **Студент** (`src/app/(student)`): навигация из 4 разделов — Главная · Расписание · Учёба · Заявки; справа в шапке — «Помощник», уведомления (колокольчик), профиль (аватар; «Ещё» объединено с профилем, `/more` → редирект).
  - Главная (разгружена): приветствие + одна фраза о дне, тёмная карточка ближайшей пары, «Требует внимания» (3 дела + «Показать ещё»), 3 плитки. Самочувствие — в профиле, объявления — в «Уведомления → Объявления».
  - Расписание: один выбор дня (число пар под датой), по умолчанию ближайший учебный день; карточка пары: время → предмет → аудитория, мелко вид/преподаватель.
  - Учёба: сводка «как у меня дела», семестры, сессия, пересдачи.
  - Заявки: 7 типов, трекер статусов, PDF-справка с QR + публичная `/verify/[code]`, «нужна бумага с печатью».
  - Помощник: выездная панель (по мотивам my.itmo), история чатов (`AiChat`), черновик заявки → заполненная форма. Иконка — сгенерирована OpenAI (`public/ai/assistant.webp`, исходник `docs/assistant-icon-source.png`). Имя «Уни» отменено — просто «Помощник».
- **Деканат** (`src/app/staff`): «Заявки студентов» = входящие с вкладками Новые / В работе / Ждут студента / Готовы к выдаче / Архив + кнопка действия в строке; карточка заявки — кнопки решений (Одобрить / Справка готова / Запросить уточнение / Отклонить); Объявления; Расписание (перенос/отмена пары → уведомления группе).
- **Преподаватель** (`src/app/teacher`): главная «Сегодня» (пары дня → «Оценки группе» / «Журнал»), журнал с «+ Оценка» одному студенту, «Оценки группе» за одну работу (`/teacher/[g]/[c]/bulk`) → студентам уведомление «Новая оценка».

**Дизайн-система v3** (`src/app/globals.css`, `src/components/ui.tsx`): по мотивам rondesignlab.com — фон #FAFAFA, шрифт **Onest** (Urbanist без кириллицы), крупные заголовки, навигация-капсулы (активная чёрная), чёрные кнопки-пилюли, карточки 24–32 px, пастели со смыслом: мятный — справки, голубой — расписание, сиреневый — учёба, жёлтый — помощник/важное. Логотип — «УНИВЕР» шрифтом Unbounded, где «Е» из трёх плашек (`src/components/logo.tsx`). Вход — в стиле образца ITMO ID: фон сгенерирован OpenAI (`public/bg/login.webp`) + SVG-подложка. ## 5. Ключевые решения (не пересматривать без команды)
- Роли: студент, деканат, преподаватель. Полноценной админки нет (данные из сида).
- ИИ-помощник: у команды **свой ключ к шлюзу-агрегатору моделей** (работает из РФ и из-за рубежа), OpenAI-совместимый: `AI_PROVIDER=gateway`, `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` в `.env` на сервере. Без ключа — режим правил (`src/server/ai/assistant.ts`). GigaChat не нужен.
- Хостинг: **VPS на Jino** (2 vCPU, 8 ГБ RAM, Россия), SSH `root@7d965724e284.vps.myjino.ru -p 49264`; без своего домена — HTTPS через Caddy/Let's Encrypt на технический поддомен. **На сервере уже есть чужие сервисы** — ставить изолированно в `/opt/univer`, сначала только осмотр (порты 80/443, docker).
- Репозиторий: `github.com/SetOffice24/digital-dekanat` (приватный). **Push и любые действия на сервере — только по явной команде пользователя.**
- Платные генерации (OpenAI Image через `C:\Users\User\Desktop\SetSearch site creation\SetSearch.ai\tools\gen-image.mjs`, ключ — пользовательская переменная Windows `OPENAI_API_KEY`, `NODE_USE_ENV_PROXY=1`) — только с согласия, называть количество.
- Fable — для архитектуры/аудита; Opus — сборка и оркестрация; Sonnet-субагенты — изолированные куски (кабинет сотрудника, журнал преподавателя) с чётким брифом «не трогай файлы X».
- Общие правила для любых ИИ-агентов — `AGENTS.md`. Предложения и асинхронные обсуждения между агентами — `docs/agents/ideas/`: одна идея — отдельная карточка, итог обсуждения не заменяет явное решение команды о реализации.

## 7. Подводные камни окружения
- **Docker Desktop локально не стартует** → для разработки встроенный PostgreSQL (`scripts/dev-db.mjs`, UTF-8 обязательно). Если фоновый процесс БД умер — запустить `corepack pnpm db:local` снова.
- **`prisma migrate dev` интерактивна** в этой среде → новые миграции: `prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script > prisma/migrations/<ts>_<name>/migration.sql`, затем `prisma migrate deploy`.
- **`prisma generate` падает, пока работает dev-сервер** (Windows блокирует DLL) → остановить превью, сгенерировать, запустить снова.
- **PowerShell 5 пишет UTF-8 с BOM** (`Set-Content -Encoding utf8`) → ломает package.json; писать через `[IO.File]::WriteAllText(path, text, New-Object System.Text.UTF8Encoding($false))` или инструментом Write.
- **`db:seed` сбрасывает сессии** → после сида все выходят из аккаунтов.
- **Chrome подставляет сохранённый логин** при входе → поле дописывается («dekanatteacher»); при тестах задавать значения через form_input. Скриншоты в Chrome не снимаются, если окно в фоне — визуал проверять во встроенном браузере.
- В новых Chrome `scrollIntoView` возвращает Promise → в `useEffect` всегда фигурные скобки.
- Глобальные CSS-правила — только в `@layer base`, иначе перебивают утилиты Tailwind 4.
- **Обратные слэши теряются в `node -e` / heredoc через bash-инструмент** (регулярки `/\s+/` превращались в `/s+/`, `printf '%s\n'` — в перенос строки) → код с `\` править точечным редактированием файла, а не shell-скриптом; после правки проверять результат.
- **Dev-сервер иногда не подхватывает изменённый файл** (страница отдаёт старую версию даже после перезагрузки) → перезапустить dev-сервер.
- **Фоновый PostgreSQL (`db:local`) может завершиться сам** (выход с кодом 4) → снова `corepack pnpm db:local`; затем при необходимости `db:seed`.
- **Тесты меняют демо-данные** (сдают ДЗ, ставят отметки) → после `corepack pnpm test` перед ручной проверкой или демо снова выполнить `db:seed`.
