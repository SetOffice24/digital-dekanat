## C01 · Новое · P2 · Фокус выходит из модального помощника на скрытую страницу

**Воспроизведение:** студент → страница дела → открыть помощника → фокус автоматически в поле ввода → нажимать Tab.

Наблюдаемая последовательность: поле ввода → «Сказать голосом» → вне диалога → элементы страницы («Главная», «Сообщения», «Уведомления», «Профиль», «← Мой день», «Написать в деканат»). На фоне виден модальный помощник, но клавиатура уже управляет перекрытой страницей. Переходы проверены настоящими клавишами, а положение фокуса — `document.activeElement.closest('[role="dialog"]')`. После первых шагов значение стало false.

При этом у контейнера действительно есть `role="dialog"` и `aria-modal="true"`; проблема не в отсутствии имени. Escape работает и закрывает панель. После первого закрытия из поля ввода активным элементом стал BODY, а не кнопка, открывшая помощника. Уход на скрытую страницу и потеря возврата фокуса — две части одного дефекта управления модальным окном.

**Причина в коде:** `src/components/assistant/provider.tsx:15` обрабатывает Escape и запрещает прокрутку body, но не удерживает фокус внутри панели, не исключает фон из клавиатурной навигации и не восстанавливает элемент открытия. Модальная разметка начинается на строке 32. `assistant-panel.tsx` фокусирует поле при открытии; это не заменяет полный цикл управления фокусом.

**Последствие:** пользователь клавиатуры теряет контекст и может активировать скрытую ссылку вместо действия помощника. Это не доказательство нарушения серверных прав доступа.

**Рекомендация:** обеспечить завершённое поведение модального окна: сохранить инициатор открытия; перевести фокус в панель; ограничить Tab/Shift+Tab её доступными контролами; исключить фон из взаимодействия; вернуть фокус на инициатор после закрытия, если он ещё существует. Предпочтительна единая реализация для всех ролей. Не добавлять новую библиотеку без принятого в проекте согласования.

**Приёмка:** минимум два полных цикла Tab и Shift+Tab в помощнике на телефоне и компьютере; ни один шаг не попадает на фон. Проверить пустой чат, историю чатов, выключенную отправку, загруженный ответ. Escape и кнопка закрытия возвращают фокус на кнопку открытия. Если инициатор исчез после перехода, предусмотрен осмысленный запасной элемент.

## C04 · Рекомендация · P3 · В прошлом семестре недостаточно явно разделены периоды показателей

При выбранном втором семестре вверху остаются «2 курс · 3 семестр», 4,57, 0 долгов и 34 дня до будущей сессии; ниже у выбранных итогов показано «Средний балл 4,50». Данные могут быть корректны: общая сводка и выбранный семестр имеют разный охват. Недостаточно ясно именно визуальное разграничение.

Предложение: назвать верхний блок «Сейчас / за всё время», а список — «Итоги второго семестра». Для двух средних явно указать периоды видимой подписью, а не только подсказкой. При этом не пересчитывать текущие долги и будущую сессию по прошлому семестру ради визуального согласования.
