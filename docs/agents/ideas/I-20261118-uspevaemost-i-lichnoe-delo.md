# Успеваемость для деканата и преподавателя, личное дело студента

- **Статус:** Реализовано
- **Автор:** Claude Code (Opus)
- **Дата создания:** 2026-11-18
- **Область:** продукт / UX
- **Связанные документы:** `docs/00-tz.md`, `docs/HANDOFF.md`, `AGENTS.md` (раздел «Продукт и дизайн»), `src/server/repos/student.ts` (`summarize`), `src/server/repos/attendance.ts`, `src/server/repos/homework.ts`, `src/app/staff/attendance/**`, `src/app/teacher/[groupId]/[courseId]/page.tsx`

## Проблема

Успеваемость сейчас видит только сам студент («Учёба»). У деканата нет ни ведомости, ни статистики по группам — только заявки, расписание и посещаемость. У преподавателя есть журнал и посещаемость по одной дисциплине, но нет сводки по группе и одного места, где видно всё о студенте. Команда попросила «чтобы у администраторов и у преподавателя была видна статистика по их студентам».

## Предложение

**Деканат.** Пункт меню «Посещаемость» превращается в раздел «Студенты» (меню остаётся из 4 пунктов: Заявки · Студенты · Расписание · Объявления). Внутри:

1. **Сводная ведомость группы** — таблица «студенты × дисциплины текущего семестра»: в ячейке баллы и прогноз оценки («37/60 · на 3»); справа — средний балл за учёбу, долги, посещаемость, доля сданных ДЗ. Переключатель семестров (прошлые — итоговые оценки). Фильтры: с долгами, баллы ниже 60 %, посещаемость ниже 80 %, есть несданные ДЗ. Сортировка по столбцам. На телефоне — список студентов с главными цифрами вместо таблицы. **Выгрузка ведомости в Excel.**
2. **Статистика по группам** своего факультета (или всем — для деканата без привязки): студентов, средний балл, доля успевающих, долгов, посещаемость, сдано ДЗ; переход в ведомость группы.
3. **Посещаемость** — текущий экран `/staff/attendance` как вкладка раздела.
4. **Личное дело студента** (по нажатию на фамилию отовсюду): данные; успеваемость по семестрам; посещаемость по дисциплинам и пропуски; домашние задания со статусами; заявки. Здесь же позже — «Написать студенту» (карточка `I-20261118-soobshcheniya`) и управление аккаунтом.

**Преподаватель.**
- Над журналом дисциплины — статистика группы: средний балл, распределение по прогнозу оценок («на 5 — 3, на 4 — 6, на 3 — 2, ниже — 2»), посещаемость, сдача ДЗ (вовремя / с опозданием / не сдали).
- Карточка студента в разрезе дисциплины: оценки с датами, посещения, ДЗ.
- На главной — короткая сводка по всем его группам: где средний балл ниже порога, у кого пропуски подряд, сколько работ ждут проверки.

Границы: таблицы БД не меняются — только новые выборки (`src/server/repos/analytics.ts`) и экраны. Студенту ничего нового в этой карточке (у него «Учёба»).

## Ценность и соответствие проекту

Закрывает роль деканата как «администратора успеваемости» и даёт преподавателю картину по группе — это часть «цифрового деканата» из ТЗ. Пороги прогноза (60/75/90 % от возможного) уже используются в «Учёбе» студента — те же правила, чтобы цифры совпадали у всех ролей.

## Альтернативы

- Только список «проблемных» студентов без ведомости — проще, но деканату нужна именно ведомость (привычный документ) и выгрузка.
- Отдельный BI-дашборд с графиками — тяжелее и хуже на телефоне; для прототипа — избыточно.

## Риски и ограничения

- Права: сотрудник с привязкой к факультету — только свой факультет; преподаватель — только свои пары (группа + дисциплина, где у него есть занятия). Нужны тесты на чужой факультет/группу.
- Производительность: агрегаты по группе в одном-двух запросах, без N+1.
- Excel: новая зависимость `exceljs` в рабочем сервисе (MIT) — одобрено командой 18.11; выгрузка только для своей области доступа, имя файла без персональных данных сверх ФИО вымышленных студентов.
- Таблица на 360 px не помещается — обязательна мобильная версия списком.

## Критерии проверки

- Деканат: ведомость ИВТ-24-1 показывает тех же студентов и те же баллы, что видят студенты в «Учёбе»; фильтры сужают список; Excel открывается и совпадает с экраном.
- Сотрудник другого факультета не видит группу (404); преподаватель не видит чужую дисциплину.
- 360 px — без горизонтальной прокрутки; автотесты на права и расчёт средних/прогноза.

- **Файлы:** `src/server/repos/analytics.ts` (ведомость, статистика групп, личное дело, статистика дисциплины, сводка преподавателя), `src/lib/grading.ts` (единый прогноз оценки), `src/app/staff/students/**` (ведомость, группы, личное дело), `src/app/api/staff/gradebook/route.ts` (Excel), `src/components/staff/{students-tabs,group-select}.tsx`, `src/components/teacher/course-stats.tsx`, `src/app/teacher/[groupId]/[courseId]/student/[studentId]/page.tsx`, правки меню деканата, журнала и главной преподавателя; `exceljs` перенесён в рабочие зависимости.

- **Проверки:** `tests/analytics.test.ts` (пороги, совпадение баллов с «Учёбой» студента, долг в фильтре, прошлый семестр, чужой факультет и чужая дисциплина — нет доступа); всего 49 тестов; Chrome — деканат и преподаватель; 360 px — все новые экраны без прокрутки вбок; Excel скачивается (XLSX).
