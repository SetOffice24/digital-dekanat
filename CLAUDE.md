# Цифровой деканат будущего — правила для ИИ-агентов

Прототип личного кабинета студента для конкурса. Общаться с командой на русском.

## С чего начать новую сессию
**Сначала прочитать `docs/HANDOFF.md`** — текущее состояние, как запустить, аккаунты, принятые решения, открытые задачи и подводные камни окружения. Потом — нужные документы ниже.

## Документы
- `docs/HANDOFF.md` — состояние проекта и план (обновлять при крупных изменениях).
- `docs/00-tz.md` — требования конкурса и критерии. Сверяться перед каждой фичей.
- `docs/01-research.md` — исследование и исходный состав разделов.
- `docs/ARCHITECTURE.md` — исходная архитектура (частично устарела; фактическое состояние — в HANDOFF).
- `docs/test-accounts.md` — тестовые аккаунты для жюри.
- `docs/licenses.md` — лицензии шрифтов, картинок, иконок.
- `docs/process-log.md` — журнал работы с ИИ. **После каждого значимого шага добавлять запись**: задача, модель/инструмент, ключевой промпт, результат, ошибки ИИ и как исправили. Это половина оценки по критерию «нейротехнологии».

## Жёсткие правила
- Только вымышленные данные. Никаких реальных ФИО, номеров зачёток, логинов вуза.
- Без логотипа реального вуза. На сайте — пометка «концепт для конкурса, не официальный сервис».
- Секреты (ключи ИИ, пароли БД) — только в переменных окружения на сервере, никогда в коде, в git и в браузере. `.env` в `.gitignore`.
- Каждый запрос к данным фильтруется по пользователю из сессии (только через `src/server/repos/*`); доступ по чужому ID — 404/403. На это — автотесты.
- Mobile-first: всё проверять на ширине 360 px и на широком экране.
- Сторонние шрифты/иконки/картинки — только с разрешающей лицензией; лицензию указывать в `docs/licenses.md`.
- **Push на GitHub и любые действия на VPS — только по явной команде пользователя.** Платные генерации картинок — только с согласия.

## Дизайн и навигация (требования команды)
- Простота важнее количества: «нужное за пару касаний», ничего не мельтешит, функционал не теряем — второстепенное прячем за ссылками/кнопками «Показать ещё».
- Студент: 4 раздела (Главная · Расписание · Учёба · Заявки) + действия в шапке (Помощник, уведомления, профиль). Новые разделы — только по согласованию.
- Стиль v3: фон #FAFAFA, Onest, капсулы, чёрные кнопки-пилюли, карточки 24–32 px, пастели со смыслом (см. HANDOFF §4).
- Помощник называется просто «Помощник».
- Проверять результат глазами пользователя в браузере (встроенный или Chrome), а не только тестами.
