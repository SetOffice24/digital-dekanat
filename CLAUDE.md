## Специфика Claude Code
- Превью dev-сервера — конфигурация `univer` в `C:\Users\User\Desktop\SetSearch site creation\.claude\launch.json` (`preview_start name="univer"`). Не запускать dev-сервер через Bash.
- Проверка «глазами пользователя»: встроенный браузер (ширина 360 px через resize_window) и Claude in Chrome. Вход — кнопками «Демо-доступ»; в Chrome значения полей задавать через form_input/JS (Chrome подставляет сохранённый логин). Скриншоты Chrome не снимаются, если окно в фоне.
- Код с обратными слэшами (регулярки, `\n`) править инструментом Edit/Write, не через `node -e`/heredoc в Bash (см. HANDOFF §7).
- Субагентам давать полный бриф: цель, разрешённые и запрещённые файлы, критерии готовности (правила координации — `AGENTS.md`).
- Коммиты — локально после каждого законченного блока; push — только по команде пользователя.
